# Калькулятор чаевых

Пошаговый калькулятор для быстрого расчёта чаевых и дележа счёта в ресторане или кафе.

![Demo](https://img.shields.io/badge/HTML-CSS--JS-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue)

## Возможности

- **Ввод суммы счёта** — большое поле для удобного ввода
- **Чаевые** — процент (5–30%) или фиксированная сумма
- **Деление на компанию** — от 1 до 20 человек
- **Итог** — наглядная карточка с разбивкой: сумма, чаевые, итого, каждый платит
- **Сохранение настроек** — последние значения сохраняются в localStorage
